## Project Description 
<!-- Standard : Project Description  -->
This project is built with the aim of implementing a modern e-commerce website based on the design provided in Figma. The objective of this project is to practice and showcase skills in responsive design, UI/UX, organized code structuring, and the application of design principles.
---
---
---


## Features 🌏
<!-- Standard : features  -->
- Designed based on Figma 
- Completly Responsive for mobiles , tablets & dekstaps 
- Using Flexbox & Grid Structures on CSS3 
- Color scheme and typography consistent with the original design
